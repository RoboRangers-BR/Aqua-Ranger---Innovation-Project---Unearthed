## 🔍 Problem Statement

> **The difficulty of access to resources for the exploration of coastal archaeological sites.**

Marine archaeology in Brazil faces a critical shortage of professionals and affordable equipment. The numbers speak for themselves:

| 📊 Indicator | 📌 Data |
|---|---|
| 🚢 Shipwrecks in Brazil | ~11,000 — only ~1,000 catalogued, 600 effectively discovered |
| 🤿 Marine archaeologists in Brazil | ~25 (3.89% of scientific divers) |
| 🌍 Marine archaeologists worldwide | ~3,500 |
| 🏛️ Archaeological sites in Brazil | ~28,000 — underwater sites: no official count (IPHAN) |
| 💸 Cost per hour of archaeological diving | US$ 90 |

---

## 💡 Our Solution

The **Aqua Ranger** is an aquatic exploration ROV *(Remotely Operated Vehicle)* designed to **locate artifacts on the coast** — making underwater archaeological exploration safer, more accessible, and dramatically more affordable.

### ⚙️ Components

| 🔧 Component | 📋 Function |
|---|---|
| 🟠 Float (buoy) | Keeps the ROV stable at the water surface |
| 🌀 Underwater motors (×3) | Provides movement and maneuverability |
| 🔩 Metal detector sensor | Locates metallic artifacts on the seabed |
| 📷 Panoramic waterproof camera | Visual monitoring of the underwater environment |
| 🎮 Controller + monitoring screen | Remote operation from the surface |
| 🔋 12V battery + charger | Power supply |
| 📍 GPS / locator tracker | Marks coordinates of found artifacts |
| 🏗️ PVC pipe structure (75mm) | Lightweight and ballast-free frame |
